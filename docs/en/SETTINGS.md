# Settings

[UmaVR](../../README.md) · [Usage](USAGE.md) · [Installation, updates and removal](INSTALLATION.md)

## Public release v0.1.1

Close the game and open `vrmod/tools/UmaVR.Configurator.exe`. Adjust world scale if characters or the stage look too large or small in Live. Eye render scale changes image resolution. Movement speed and snap-turn angle can be set independently.

## Development build

Open the controller guide in the input tab to see your selected hands and buttons. To use character contact, read the notice to the end and accept it in the PC app before starting the game. In the development build you can choose the movement stick, world-grab button and tracked hand. When a panel is open, UI input takes priority.

# Troubleshooting

[UmaVR](../../README.md) · [Usage](USAGE.md) · [Installation, updates and removal](INSTALLATION.md)

## Install is unavailable

Close the game and select the DMM folder containing `umamusume.exe`. If Localify is missing, follow the installer’s Localify link, install it and refresh.

## No VR view

Connect the headset, check the active OpenXR runtime on the PC and start the game from DMM.

## The cursor moves but clicks do nothing

Focus the game window on the PC and try the pointer-hand Trigger again.

## Update failed

Check `%LOCALAPPDATA%\UmaVR\update.log` for the failed step.

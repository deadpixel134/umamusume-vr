# Usage and controls

[Project home](../../README.en.md) · [Installation](INSTALLATION.md) · [Architecture](ARCHITECTURE.md)

- Live uses binocular stereo and physical HMD 6DoF. Other contexts use the complete original game screen on a front panel.
- Right aim ray targets the UI; Trigger or A clicks/drags; B goes back.
- Right thumbstick moves, left thumbstick performs a 30° snap turn, and left Grip toggles the Live auxiliary panel.
- Complete hand-role swap is available in settings.

Run `vrmod/tools/UmaVR.Configurator.exe` while the game is stopped to change Camera Follow, world scale, eye render scale, locomotion, snap angle, hand roles and supported VFX controls.

Home, Story, Race, Training and character preview currently remain PANEL. Direct touch and smooth turn are unsupported. SteamVR and Meta Quest Link/Air Link have not been tested in this project.

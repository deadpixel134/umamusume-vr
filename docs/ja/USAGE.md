# 使い方と操作

[プロジェクト](../../README.ja.md) · [インストール](INSTALLATION.md) · [構成](ARCHITECTURE.md)

- Liveは両眼stereoと物理HMD 6DoFを使用し、それ以外は完全なゲーム画面を正面PANELに表示します。
- 右手aim rayで照準し、TriggerまたはAでクリック/ドラッグ、Bで戻ります。
- 右スティックで移動、左スティックで30°snap turn、左GripでLive補助パネルを切り替えます。
- 設定で左右の役割全体を交換できます。

ゲーム停止中に`vrmod/tools/UmaVR.Configurator.exe`を使い、Camera Follow、world scale、eye render scale、移動、snap角度、手の役割、対応VFXを変更します。

Home、Story、Race、Training、キャラクタープレビューは現在PANELです。直接タッチとsmooth turnは未対応です。SteamVRとMeta Quest Link/Air Linkは未検証です。

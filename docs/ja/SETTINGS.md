# 設定

[UmaVR](../../README.ja.md) · [使い方](USAGE.md) · [インストール・更新・削除](INSTALLATION.md)

## 公開版 v0.1.1

ゲームを終了して `vrmod/tools/UmaVR.Configurator.exe` を開きます。ライブでキャラクターやステージが大きすぎる、または小さすぎる場合はワールドスケールを調整します。両眼の描画倍率は映像の解像度を変えます。移動速度とスナップターン角度は個別に設定できます。

## 開発ビルド

入力タブの操作ガイドで、選択中の手とボタンを確認できます。キャラクター接触を使うには、ゲームを起動する前にPC設定で案内を最後まで読んで同意してください。 開発ビルドでは移動用スティック、ワールド移動のボタン、追跡する手を選べます。パネルを開いている間はUI操作が優先されます。

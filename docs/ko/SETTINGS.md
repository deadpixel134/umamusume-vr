## 공개판 v0.1.1

게임을 종료하고 `vrmod/tools/UmaVR.Configurator.exe`를 엽니다. Live에서 캐릭터와 무대가 너무 크거나 작게 보이면 월드 스케일을 조절하세요. 눈별 렌더 배율은 영상 해상도를 바꿉니다. 이동 속도와 스냅 회전 각도는 따로 조절할 수 있습니다.

## 개발 빌드

입력 탭의 조작 안내에서 현재 선택한 손과 버튼을 확인하세요. 캐릭터 접촉은 PC에서 안내를 끝까지 읽고 동의한 뒤 게임을 시작해야 동작합니다. 개발 빌드는 이동 스틱, 월드 잡기 버튼과 추적 손을 설정할 수 있습니다. 패널이 열려 있으면 UI 조작이 우선합니다.

# 업데이트

## 업데이트하기 · v0.1.1

게임을 완전히 종료하고 `vrmod/tools/UmaVR.Configurator.exe`를 엽니다. 공개판 v0.1.1은 시작할 때 새 공개판을 확인하며, **업데이트 확인**으로 다시 조회할 수 있습니다. 새 버전이 있으면 ZIP 검증 후 설치기를 자동으로 실행합니다.

## 수동 업데이트

1. 릴리스의 **Assets**에서 같은 버전의 `UmaVR-vX.Y.Z.zip`과 `.zip.sha256`을 받습니다.
2. 수동으로 진행하려면 [Releases](https://github.com/deadpixel134/umamusume-vr/releases)의 새 버전 ZIP을 게임 폴더 밖에 풀고, 해당 `UmaVR.Installer.exe`에서 기존 게임 폴더를 선택해 설치하세요.

## 자동 업데이트가 멈췄을 때

게임 실행 중이라는 메시지가 뜨면 게임을 종료한 뒤 **업데이트 확인**을 다시 누릅니다. 다운로드·검증 오류는 설정 프로그램의 상태 메시지에서 확인합니다. 설치기가 실행된 뒤 실패했다면 `%LOCALAPPDATA%\UmaVR\update.log`에서 마지막 오류를 확인하세요.

## 개발 빌드 v0.1.12

이 빌드에서는 새 버전 확인 후 **적용**을 눌러 설치를 시작합니다. 기존 설치 구조나 수정된 파일 때문에 수동 확인이 필요하다고 표시되면 설치기가 지정한 경로와 파일을 먼저 확인하세요.

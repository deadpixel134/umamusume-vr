# 문제 해결

[UmaVR](../../README.ko.md) · [사용 방법](USAGE.md) · [설치·업데이트·제거](INSTALLATION.md)

## 설치할 수 없음

게임을 종료하고 `umamusume.exe`가 있는 DMM 설치 폴더를 선택하세요. Localify가 감지되지 않으면 설치기의 안내로 설치한 뒤 새로고침하세요.

## VR 화면이 열리지 않음

헤드셋을 연결하고 PC에서 활성 OpenXR 런타임을 확인한 뒤 DMM에서 게임을 시작하세요.

## 커서는 보이지만 클릭되지 않음

PC에서 게임 창을 한 번 선택한 뒤 포인터 손의 Trigger로 다시 시도하세요.

## 업데이트 실패

`%LOCALAPPDATA%\UmaVR\update.log`에서 실패한 단계를 확인하세요.

# UmaVR v0.1.1

Controller 이동과 설정을 개선한 업데이트입니다.

## 변경 사항

- Controller 이동 속도의 고정 `5.00` 상한을 제거했습니다. 유효한 `0 이상` 값을 저장할 수 있습니다.
- 새 기준 이동 속도는 `5.00`입니다.
- 월드 스케일 이동 속도 자동 보정 체크박스를 Controller 설정에 추가했습니다.
- 자동 보정 ON에서는 `기준 속도 × world scale ÷ 2.00`을 적용합니다. OFF에서는 입력 속도를 직접 사용합니다.
- schema 1~9 설정은 기존 이동 감각을 바꾸지 않도록 자동 보정 OFF로 migration합니다.
- 한국어·영어·일본어 README에 Localify Credits를 추가했습니다.

## 설치 및 업데이트

- `UmaVR-v0.1.1.zip`을 풀고 최상위의 `UmaVR.Installer.exe`를 실행하십시오.
- 기존 v0.1.0 사용자는 Configurator의 업데이트 확인 기능으로 v0.1.1을 검색할 수 있습니다.
- 기존 설정과 다른 Localify `externalDlls` 항목은 보존됩니다.
- Localify가 감지되지 않으면 인스톨러의 [공식 Localify 설치 안내](https://github.com/Kimjio/umamusume-localify)를 이용하십시오.

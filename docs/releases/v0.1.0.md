# UmaVR v0.1.0

첫 공개 릴리스입니다.

## 포함 사항

- 검증된 Live OpenXR stereo, 물리 HMD 6DoF, world scale와 Camera Follow
- 원본 게임 최종 화면을 사용하는 FLAT 정면 패널과 IMMERSIVE 보조 패널
- controller ray/cursor/click/back, locomotion, 30° snap turn과 전체 손 역할 전환
- 한국어·영어·일본어 설정 프로그램과 설치 프로그램
- exact GitHub Release asset/version/SHA-256/package-manifest 검증을 사용하는 자동 업데이트 경로
- 기존 설정과 다른 Localify `externalDlls` 항목을 보존하는 설치·제거·롤백 구조

## 설치 전 확인

- Windows 11 x64, DMM판 우마무스메, Direct3D 11과 PC OpenXR 환경이 필요합니다.
- 이 버전은 기존 Localify 1.50.0의 `localify.dll` 및 루트 `config.json` loader를 필요로 합니다.
- Localify가 감지되지 않으면 인스톨러의 [공식 Localify 설치 안내](https://github.com/Kimjio/umamusume-localify)를 이용하십시오. UmaVR가 Localify를 자동 설치하거나 교체하지는 않습니다.
- 게임을 완전히 종료한 뒤 `UmaVR.Installer.exe`를 실행하십시오.
- 압축 최상위의 유일한 EXE가 인스톨러이며, 인스톨러와 Configurator는 별도 .NET 설치가 필요 없는 self-contained 단일 파일입니다.
